# 1forma.ru

Тестовый macOS desktop-проект на базе Pake для сайта `1forma.ru`.

Цель:

- открыть `1forma.ru` в отдельном приложении на Mac;
- проверить авторизацию через обычные cookies/session;
- сохранить вход между перезапусками, если сайт это позволяет.

Важно:

- сайт должен открываться в достаточно широком desktop-viewport;
- если окно слишком узкое, часть верстки может схлопываться и меняться как в responsive-режиме;
- для `1forma.ru` лучше стартовать с большого окна, а не с компактного.

Пока здесь будут лежать:

- `config.json` или аналогичный конфиг Pake;
- иконка приложения;
- заметки по авторизации и поведению сайта.

Также можно подключать локальные инъекции:

- `transition.js` для мягкой анимации между переходами;
- при необходимости CSS-инъекции для точечного управления webview-оболочкой.
