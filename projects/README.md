# Projects

Каждый тестовый desktop-проект живет в своей отдельной папке внутри `projects/`.

Рекомендуемый формат:

- `projects/<site-name>/`

Примеры:

- `projects/notion/`
- `projects/chatgpt/`
- `projects/internal-portal/`

Идея простая:

- у каждого сайта свои настройки;
- у каждого сайта свой `README.md` с URL и заметками по авторизации;
- при необходимости можно держать рядом иконку, скриншоты и конфиг.
